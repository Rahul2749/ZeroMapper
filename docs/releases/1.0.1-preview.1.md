# 1.0.1-preview.1

Unpublished patch preview for the 1.x flat-mapping API.

- Reuse emitted source when semantic analysis produces the same mapper model. Edits that change a binding still regenerate the affected mapper.
- Add warning `ZM008` for a readable source match skipped on creation because the destination has no public setter or init accessor. Use `[MapIgnore(nameof(Destination.Property))]` to acknowledge the omission. Builds that treat warnings as errors may require this change when upgrading.
- Bound generated filename lengths using a short class prefix and a stable hash of the fully qualified mapper name.
- Embed the generator's PDB with Source Link, record the repository commit in each package, and verify both against the build commit before release.
- Clarify create versus update defaults, shallow references, and the security reporting instructions.
