# 0.0.1-preview.1

Initial experimental preview, published on 21 October 2026. API compatibility is not guaranteed between previews.

## Included

- Incremental C# source generator with direct property assignments.
- Exact-name matching, implicit conversions, nullable diagnostics, required/init properties, and inherited property handling.
- Protected destination members, explicit ignores, and mandatory allow-lists for existing-object updates.
- Three packages: ZeroMapper, ZeroMapper.Abstractions, and ZeroMapper.Generator.
- Compiler/execution tests, allocation checks, example application, and benchmark harness.

## Requirements and limits

Use C# 12 or later. Package assemblies target .NET Standard 2.0. Compatible reference properties are shared, not deep-copied. Nested/collection conversion, constructor binding, flattening, projection, fluent configuration, runtime mapping and DI integration are not included. Signing, SourceLink and AOT/trim verification remain future release work. Do not treat the preview mapper as a substitute for validation or authorization.

## Release evidence

Run `eng/prepare-release.ps1` with the .NET 10 SDK and PowerShell 7. It restores, cleans, builds, tests, checks package metadata and budgets, then installs the actual packages in isolated .NET 8 and .NET 10 consumers. It writes the candidate packages, a test report and SHA-256 manifest under `artifacts`.

All 35 tests passed on 21 October 2026 before packaging preparation. The generated manifest and TRX report are the authoritative evidence for the final candidate. Timing benchmarks are not a release claim.

Install from [NuGet](https://www.nuget.org/packages/ZeroMapper/0.0.1-preview.1):

```shell
dotnet add package ZeroMapper --version 0.0.1-preview.1
```
